# pluto-download-installers
Latest installers for Pluto application

As an indie developer, this app is not digitally signed by Microsoft or Apple yet.

## Windows Users
You may see a SmartScreen blue window. Click "More Info" > "Run Anyway".

## macOS Users
You might see a warning saying "Pluto is damaged and can't be opened" or "Unidentified Developer". This is a standard gatekeeper message for unsigned apps. Detailed instructions on how to bypass this (using a quick Terminal command) are included in the download ZIP.
